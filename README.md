# VINTHA

### See it. Save it. Don't forget it.

VINTHA is an India-first app designed to turn things you discover online into real-world experiences.

You see a restaurant, café, store, event, or interesting place on social media and think:

> "I want to go there someday."

Instead of saving the post and forgetting about it, share it with VINTHA.

VINTHA helps identify the place, saves it for you, and can remind you when you're nearby.

## The idea

**Discover → Save → Remember → Experience**

## Core Experience

1. Discover something interesting online.
2. Share it with VINTHA.
3. VINTHA identifies and saves the place.
4. The place appears on your personal map.
5. When you're nearby, VINTHA reminds you.
6. You finally experience the place you saved.

## Initial MVP

- Social media sharing
- Place identification
- Saved places
- Personal map
- Location-based reminders
- Place details
- Original source link

## Vision

VINTHA aims to become a personal discovery layer for the real world — helping people turn digital discoveries into places, experiences, and memories.
